# MikeShe
MIKE SHE is an integrated hydrological modelling system for building and simulating surface water flow and groundwater flow. 

This repository stores MIKE SHE plugins, processing scripts and other MikeShePy examples:

| Folder | Content |
|---|---|
| `DataProcessing` | Scripts that read and write MIKE SHE files outside a simulation |
| `Plugins` | Python plugins that MIKE SHE runs during a water movement simulation |
| `SimulationExecution` | Scripts that run simulations from `python.exe` through `MShePy` |
| `EngineInterfaces` | The C interfaces of the water movement and water quality engines from Python, and the WM-WQ coupling built on them |
